# Project Portfolio

AI security agents, an iOS app, sales-engineering tools, interactive explainers and games.

**Live gallery:** https://iautomatecontracts-lang.github.io/portfolio/

## Security & identity

| Project | What it is | Stack |
|---|---|---|
| [Okta AI Sentinel](security/okta-ai-sentinel) | A security agent that watches an Okta org's System Log and flags when **an AI system is calling the Okta API** (LLM agents, MCP servers, headless browsers, agent OAuth grants). Heuristic scoring, then Claude triage, then Slack alerts with optional containment. | Python, FastAPI, Claude API, pytest |
| [Auth0 AI Sentinel](security/auth0-ai-sentinel) | The same idea for Auth0 tenant logs: Log Stream webhook or Management API polling, detection that knows about Token Vault and token exchange, and Claude verdicts. | Python, Claude API, pytest |
| [Auth0 AI Sentinel deck](decks) | A slide deck made from the Auth0 Sentinel README, generated by code. | PptxGenJS |
| [OAuth 2.0 Field Course](web/oauth-field-course.html) | A self-paced interactive course: a step-through of the auth code + PKCE flow, a JWT claim explorer, a scopes/consent lab, OAuth vs OIDC vs SAML, and quizzes. | HTML/JS |

## Running things

- **HTML projects:** open the file in a browser. Each is a single self-contained file.
- **Sentinels:** `pip install -r requirements.txt`, copy `.env.example` to `.env`, then `python -m okta_ai_sentinel` (or `auth0_ai_sentinel`). Run the tests with `pytest`. Each folder's README has the details.
- **FinePrint:** open `apps/fineprint/FinePrint.xcodeproj` in Xcode 16+ and run it on a simulator. Add your own Anthropic API key in Settings.
- **Deck:** `cd decks/deck-builder && npm install && node build.js`.
